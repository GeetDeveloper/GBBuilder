# GBBuilder

A tool that bundles source files to make Game Boy games with no extra libraries.



The main goal of GBBuilder is to make Game Boy development easier with no need for shell operations, extra packages/libraries, etc. You just need Python, your source files and to run the python codes.



##### Requirements:

These are the things you will need to use GBBuilder:

* A copy of Python (3.14.6 or newer)
* Your own assembly code (.asm or .txt)
* Your own graphics (.png, .jpeg or .bmp)
* Your own midi songs (.mid, duh.)
